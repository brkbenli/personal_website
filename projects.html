Sample Searcher

This is my Full Stack website. I make music professionally as a hobby and I often struggled to find old samples easily to use in songs. So I created this full stack web application. I made it with a React frontend, and used a MySQL database and ran the backend server on an AWS EC2 instance. I created a Python file that web scraped the music data from a website into my database including over 2000+ songs.

Beat Sequencer

This is a beat sequencer I made fully with Python! It is similar to the channel rack in FL Studio, and it has active playback, grid selection, tempo adjustment for the speed it plays at, and it plays the selected sounds when you press the spacebar. It also has volume adjustment for the sounds so you can mix the beat! It also has 3 different modes for the length of the beat.
